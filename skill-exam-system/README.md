# 职业技能实操预约评分系统

面向职业技能鉴定的实操考试管理系统，支持 **电焊、烹饪、汽修、美容** 四个工种。
考生在线预约后，系统自动安排 **工位、耗材、考评员**；考评员现场按
**操作步骤、成品质量、安全行为** 三类标准评分；考试结束后管理员发布成绩并
导出评分表，**考生只能查看本人成绩**。

## 技术栈

- Python 3.11 + Flask 3 + SQLite（零外部服务依赖）
- Jinja2 服务端渲染，pytest 端到端测试

## 快速开始

```bash
cd skill-exam-system
pip install -r requirements.txt          # 仅 Flask
flask --app run init-db                  # 建库 + 写入基础数据
python run.py                            # 启动：http://127.0.0.1:5000
```

演示账号：

| 角色   | 账号 | 密码 |
|--------|------|------|
| 管理员 | admin | admin123 |
| 考评员 | examiner01（电焊）/ examiner02（烹饪）/ examiner03（汽修）/ examiner04（美容） | exam123 |
| 考生   | candidate01 / candidate02 | cand123 |

## 角色与功能

### 考生
- 注册/登录，浏览开放场次并预约
- 预约成功即自动分配：工种空闲**工位** + 有资质且负载最低的**考评员**，
  并按工种配置**扣减耗材库存**（库存不足则预约失败；取消预约自动返还耗材）
- 查看本人已发布的成绩与逐项明细（未发布前不可见）

### 考评员
- 查看分配给自己的考评任务
- 现场评分：按工种的评分标准逐项打分（步骤/成品/安全），可附评语
- 提交后自动汇总总分，满分 60% 为合格线；可修改评分

### 管理员
- 场次管理：创建/停止预约/标记结束
- 资源管理：工位（可用/维护）、耗材（库存/补货）、考评员（账号与资质）
- 成绩发布：按场次批量发布，发布后考生方可查看
- 评分表导出（CSV，UTF-8 BOM，Excel 可直接打开）：
  - 场次成绩汇总表（含步骤/成品/安全分项得分）
  - 单个考生详细评分表（逐项得分与评语）

## 隐私与安全设计

1. **成绩隔离**：考生端所有成绩查询强制 `candidate_id = 当前用户` 且
   `published = 1`；访问他人成绩一律提示"不存在"，不泄露任何信息
2. **角色控制**：`role_required` 装饰器保护各端接口，考生无法访问
   管理端导出接口
3. **考评隔离**：考评员只能评分分配给自己的预约（越权返回 403）
4. **数据完整性**：预约事务化（建预约+扣库存+耗材明细），
   同场次同工位唯一约束防止超售，密码哈希存储

## 运行测试

```bash
python -m pytest tests/ -v
```

覆盖：完整业务流程、重复预约拦截、工位约满、取消返还耗材、
考评员越权评分、考生成绩隐私隔离。

## 目录结构

├── run.py                 # 启动入口（flask --app run init-db 初始化）
├── app/
│   ├── __init__.py        # 应用工厂
│   ├── db.py / schema.sql # 数据库连接与表结构

│   └── static/style.css
└── tests/test_flows.py    # 端到端测试
