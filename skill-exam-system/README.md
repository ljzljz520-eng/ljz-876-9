# 职业技能实操预约评分系统

面向职业技能考核场景的一体化管理系统，覆盖 **考生预约 → 资源自动调度（工位/耗材/考评员）→ 现场评分（步骤/成品/安全）→ 成绩导出** 全流程。

## 功能特性

### 考生端
- 注册、登录
- 按工种（电焊/烹饪/汽修/美容）浏览可预约场次
- 一键预约：系统**自动分配工位、考评员，并预留扣减耗材库存**
- 取消预约（耗材自动回补库存）
- 查看**本人**成绩与评分明细（无法查看他人成绩）

### 考评员端
- 查看分配给自己的考评任务
- 现场评分：按 **操作步骤 / 成品质量 / 安全行为** 三大类逐项打分，支持扣分备注与总评语
- 实时合计分数、分数范围校验（0~满分）
- 标记缺考、修改评分

### 管理端
- 总览看板（工种/工位/考评员/考生/预约/评分统计，耗材库存预警）
- 工位管理（增删、启停）
- 耗材管理（库存、每场用量、入库）
- 场次管理（创建、开放/关闭、容量）
- 考评员账号管理
- **导出评分表**：
  - CSV 批量导出（按场次或全部，UTF-8 BOM，Excel 直接打开不乱码）
  - 单个考生可打印评分表（含签字栏）

## 权限与数据安全

| 数据 | 考生 | 考评员 | 管理员 |
|---|---|---|---|
| 预约考试/取消 | ✅ 本人 | — | — |
| 查看成绩 | ✅ **仅本人**（越权访问返回404） | 仅自己考评的预约 | ✅ 全部 |
| 评分 | — | ✅ 仅分配给自己的考生（否则403） | — |
| 导出评分表 | ❌ 403 | ❌ 403 | ✅ |

- 密码使用 Werkzeug PBKDF2 哈希存储
- 所有需要登录的页面均有会话校验，角色越权访问返回 403

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动（首次运行自动建库并写入种子数据）
python3 run.py

# 3. 访问 http://localhost:5000
```

## 关键设计

### 资源自动调度
预约时在事务内（SQLite 使用 `BEGIN IMMEDIATE` 加写锁）依次检查：
1. 场次开放且未开始、考生未重复预约、场次未满
2. 该场次仍有**空闲工位**（同工种、启用、未被占用）
3. 该场次仍有**空闲考评员**（同工种、未被占用）
4. 所有耗材库存充足 → 扣减并生成占用记录

任一条件不满足则整体回滚。取消预约时回补耗材。经并发压测验证：
10 人同时抢容量 4 的场次，恰好 4 人成功且工位/考评员无重复分配。

### 评分模型
每个工种一套评分标准（`ScoreItem`），按 `step/product/safety` 三类组织，
各项有独立满分；考评员逐项打分，系统自动汇总分类小计与总分。

### 成绩隔离
考生侧所有成绩查询均强制过滤 `candidate_id = 当前用户`，
访问他人成绩详情返回 404（不暴露记录存在性）；导出接口仅管理员可用。
